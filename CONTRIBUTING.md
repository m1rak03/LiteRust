# Участие в разработке

Начните с небольшого изменения, описывающего конкретную проблему. Укажите способ воспроизведения и выполненные проверки в pull request.

## Подготовка

Rust 1.89+; для Windows — MSVC Build Tools и Windows SDK. Для UI-проверок — Node.js, Playwright и Chromium. Используйте зависимости из Cargo.lock.

Выполните команды проверки из README. При изменении интерфейса приложите скриншот и проверьте узкое окно. Изменения WebView2, DPAPI, установки и VPN требуют испытаний на Windows; явно отмечайте, если выполнялась только кросс-проверка компиляции.

## Правила изменений

- Не добавляйте IPC веб-страницам: привилегированные команды доступны только доверенному интерфейсу.
- Не отключайте TLS, изоляцию сайтов и проверку адресов ради совместимости.
- Не записывайте пароли, cookies, токены, VPN-ключи или полный профиль в журналы и тестовые артефакты.
- Сохраняйте совместимость настроек профиля, миграции и приватный режим.
- Не коммитьте `target`, пользовательские профили, журналы и ключи. Проверяйте лицензии сторонних компонентов.

Для уязвимостей следуйте SECURITY.md вместо публичного описания чувствительных данных.
