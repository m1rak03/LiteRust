# LiteRust 0.18.0-alpha.7

Настройки, оформление, пароли, закладки и загрузки открываются во вкладках текущего рабочего пространства. VPN доступен с верхней панели. Для своего профиля можно сохранить палитру и включить предложение WebView2 сохранять пароли.

В инструментах печати появились A4 и Letter, ориентация, масштаб и поля. Текст верхнего и нижнего колонтитула можно изменить перед сохранением PDF. Ctrl+P открывает предпросмотр WebView2 с параметрами выбранного принтера.

Settings, appearance, passwords, bookmarks and downloads open in workspace tabs. The top toolbar includes VPN controls. Profiles can store named color palettes and opt into WebView2 password saving.

PDF export supports A4 and Letter, orientation, scale, margins and custom headers and footers. Ctrl+P opens WebView2 print preview. Physical printer options depend on the Windows driver.
