# LiteRust 0.17.0-alpha.1

## Русский

- Щёлкните правой кнопкой по вкладке и выберите «Создать группу». Выделить несколько вкладок можно с помощью Ctrl+щелчка.
- Щёлкните по заголовку группы, чтобы свернуть или развернуть её. Правой кнопкой открывается меню имени, цвета, закрепления и разгруппировки.
- Перетаскивайте вкладки на заголовки групп или рядом с другими вкладками. Чтобы вернуть вкладку в общий список, перетащите её на кнопку «+» или выберите общий список в контекстном меню.
- Перетаскивайте заголовки для изменения порядка. Закреплённые группы располагаются перед остальными. Группы исчезают, когда в них нет вкладок.
- При восстановлении сессии LiteRust открывает сохранённые группы по окнам и возвращает активную вкладку. Старые вкладки открываются в общем списке. Группы приватного окна хранятся в памяти до его закрытия.

## English

- Right-click a tab and select Create group. Ctrl-click several tabs to group them together.
- Click a group header to collapse or expand it. Right-click the header to rename, recolor, pin or ungroup it.
- Drag tabs to a group header or next to other tabs. Drag a tab onto the plus button or choose Ungrouped tabs in the context menu to move the tab out of its group.
- Drag group headers to reorder them. Pinned groups appear first. A group disappears when its last tab leaves.
- Session restore reopens groups per window and restores the active tab. Existing tabs open in the ungrouped list. Private windows keep groups in memory until they close.
