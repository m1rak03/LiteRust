# LiteRust 0.15.0-alpha.3 — удобные настройки

Настройки получили отдельную левую навигацию и поиск по всем разделам. Профили, оформление, новая вкладка, запуск, поиск, безопасность, производительность, сеть и свои иконки разделены на понятные группы.

- Поиск находит параметры независимо от открытого раздела; Ctrl+K переводит фокус в поиск.
- Несохранённые изменения запуска сохраняются при переключении разделов; напоминание возвращает к форме.
- На узком окне навигация прокручивается горизонтально.
- Настройки используют существующие элементы и команды без дополнительных WebView или фоновых таймеров.

Вход открывается на официальных страницах провайдеров. Синхронизация Chrome и автоматическое определение имени аккаунта не заявляются.

Установщик включает необходимые компоненты, создаёт ярлыки и обновляет существующую установку. Проверки Windows выполняются перед публикацией.
