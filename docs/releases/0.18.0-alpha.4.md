# LiteRust 0.18.0-alpha.4

## Локальная диагностика

- Откройте «Настройки → Диагностика», чтобы посмотреть версии LiteRust, компилятора Rust и WebView2 Runtime. Там же видны вкладки текущего пространства, число открытых WebView в окне, активные обычные профили и состояние VPN.
- Недавние ошибки показаны понятными сообщениями. Раскройте журнал компонентов, чтобы увидеть отметки времени и коды событий запуска, WebView2, окон, вкладок, сети, VPN, профилей и загрузок.
- Журнал событий локального профиля состоит из текущего и предыдущего файлов JSON Lines размером до 128 КиБ каждый. В памяти доступно до 128 последних записей. Повреждённые строки пропускаются. В приватном окне журнал событий хранится в памяти до закрытия.
- Выберите «Показать отчёт» и изучите JSON. Кнопка «Сохранить отчёт» открывает системный выбор файла. В отчёт входят версии, счётчики, состояния и коды событий. Названия профилей видны только в интерфейсе. Адреса, пути, пароли, токены, cookies и содержимое страниц отсутствуют в схеме отчёта. Сохранение выполняется локально.

## Local diagnostics

- Open Settings → Diagnostics to see LiteRust, Rust compiler and WebView2 Runtime versions, current workspace tab counts, live views, active regular profiles, and VPN status.
- Recent errors appear in plain language. Expand the component log to see timestamps and event codes for startup, WebView2, windows, tabs, networking, VPN, profiles, and downloads.
- The profile journal has a current and previous JSON Lines file of up to 128 KiB each. The view retains up to 128 recent entries. Damaged lines are skipped. Private windows keep their event journal in memory until they close.
- Preview the report, review the JSON, and choose Save report to select a destination. The report contains versions, counts, states and event codes. Profile names stay in the interface. The report schema excludes addresses, paths, passwords, tokens, cookies, and page contents. Saving takes place locally.
