# LiteRust 0.16.0-alpha.4

## Русский

- Ctrl+N открывает обычное окно. Команда «Следующее окно» переключает окна текущего профиля.
- Ctrl+W закрывает вкладку. Закрытие последней вкладки закрывает её окно.
- Вкладки можно перетаскивать по панели без перезагрузки страниц.
- При запуске с восстановлением сессии LiteRust открывает сохранённые окна, вкладки и выбранные вкладки. Положение окна восстанавливается, если оно доступно на подключённых экранах.
- Обычные окна профиля используют общие настройки, cookies и локальные данные сайтов. Приватные окна остаются в отдельном процессе с InPrivate.
- Границы интерфейсных WebView рассчитываются по общим физическим координатам, включая дробный масштаб Windows.

## English

- Ctrl+N opens a regular window. Next window switches among windows in the current profile.
- Ctrl+W closes the tab and closes its window when it was the last tab.
- Reorder tabs on the tab strip without reloading their pages.
- Session restore reopens saved windows, tabs and selections. The browser restores window positions that remain accessible on connected displays.
- Regular windows share settings and site storage within one profile. Private windows use a separate process and WebView2 InPrivate.
- Child WebView borders use matching physical coordinates at fractional DPI scales.
