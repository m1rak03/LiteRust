# LiteRust 0.18.0-alpha.6

Настройки открываются вкладкой и сохраняются вместе с сессией. Цвет фона и акцент можно выбрать отдельно. Перетаскивайте блоки главной в режиме редактирования и тяните за угол, чтобы поменять ширину. Меню VPN компактнее. Адресная строка поднимает часто используемые запросы с совпадающим началом.

Установщик регистрирует LiteRust для HTTP и HTTPS. Чтобы выбрать его браузером по умолчанию, откройте раздел «О браузере» и перейдите в параметры Windows. Google Password Manager открывается внутри LiteRust. Кнопка Яндекс ID ведёт к настройкам безопасности аккаунта.

Settings now open in a session tab. Choose background and accent colors independently, drag home widgets and resize them by the corner. The VPN panel is more compact. The address bar ranks previously used queries with matching prefixes higher.

The installer registers LiteRust for HTTP and HTTPS. Open About in settings to choose your default browser in Windows. Google Password Manager opens in a LiteRust tab. The Yandex ID button opens account security settings.
