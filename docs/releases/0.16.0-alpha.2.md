# LiteRust 0.16.0-alpha.2

## Русский

- Исправлено перетаскивание плиток на главной. Левая панель показывает подписи при наведении, а настройки остаются открытыми при смене вкладок.
- В адресной строке и на главной появились подсказки из закладок и истории. Браузер передаёт WebView2 предпочтение светлой или тёмной темы.
- Добавлены предпросмотр печати и сохранение PDF с редактируемыми колонтитулами.
- Можно выбрать русский или английский язык интерфейса. Добавлены официальные страницы входа Opera и Mozilla и ссылки на инструкции по российским TLS-сертификатам.
- Вкладки переиспользуют окружение WebView2, а завершённые операции освобождают ненужные обработчики.

## English

- Fixed start-page tile dragging, added sidebar labels on hover and kept settings open when switching tabs.
- Added bookmark and history suggestions, light and dark theme preferences for WebView2, and PDF export with editable headers and footers.
- Added Russian and English interface options, official Opera and Mozilla sign-in pages, and links to certificate installation instructions.
- Reused WebView2 resources between tabs and released completed download handlers.

This is a Windows x64 prerelease.
