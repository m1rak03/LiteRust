# LiteRust 0.18.0-alpha.2

## Фоновая активность

- В разделе «Настройки → Производительность» выберите стандартное поведение WebView2, подсказку для страниц LiteRust или подсказку для страниц LiteRust и неактивных сайтов. По умолчанию учитываются только встроенные страницы. Производительный режим возвращает стандартное поведение WebView2.
- Если разрешена обработка неактивных сайтов, LiteRust проверяет их после минуты в фоне. Видимые области Split View, закреплённые группы, загрузки, воспроизводимое медиа и обнаруженные изменения формы сохраняют обычный режим. Движок продолжает исполнять скрипты и поддерживать соединения. Автовыгрузка управляется отдельной настройкой памяти. [Режимы расхода памяти WebView2](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2_19)
- Прогресс загрузок поступает от WebView2. Открытый менеджер обновляется при получении данных или смене состояния. Панель браузера получает новое состояние только при изменении её данных.

## Background activity

- In Settings → Performance, choose normal WebView2 behavior, hints for LiteRust pages, or hints for LiteRust pages and idle sites. The default applies to built-in pages. Performance mode uses normal WebView2 behavior.
- Idle sites are assessed after a minute in the background. Visible Split View panes, pinned tab groups, downloads, playing media, and detected edits keep the normal memory target. Scripts and network connections continue running. The separate memory mode controls tab release. [WebView2 memory target](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2_19)
- WebView2 reports byte progress and state changes to the open download manager. The browser toolbar receives updates when its data changes.
