# LiteRust 0.17.0-alpha.5

## Инструменты браузера

- Откройте «Инструменты», чтобы получить доступ к печати и PDF, поиску по странице, загрузкам, истории, закладкам, калькулятору и заметкам. В разделе «Настроить панель» можно скрыть лишние кнопки. Настройка сохраняется в локальном профиле.
- Создавайте заметки, меняйте название и текст, ищите по содержимому и добавляйте ссылку на открытую страницу. Изменения сохраняются автоматически. Существующая заметка переносится при открытии обновлённого профиля. Все обычные окна профиля используют общую записную книжку. У приватного окна отдельные заметки, которые удаляются при закрытии.
- Выделите текст на странице и откройте «Инструменты → Перевести выделение…». LiteRust покажет текст, который будет отправлен при нажатии «Открыть в Google Translate». Перевод открывается на сайте Google. [Справка Google Translate](https://support.google.com/translate/answer/6142478)
- Выберите «Инструменты → Сохранить страницу». Диалог зависит от установленной версии WebView2 и типа страницы. HTML сохраняет основной документ. Если доступны MHTML или полная HTML-страница, можно также сохранить поддерживаемые ресурсы. Формы, скрипты и данные внешних сервисов могут требовать подключения для полноценной работы. При недоступности API LiteRust покажет сообщение. [WebView2 Save As](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2_25)

## Browser tools

- Open Tools to reach print and PDF, find in page, downloads, history, bookmarks, calculator, and notes. Use Customize tools to choose which buttons appear. The local profile stores your choices.
- Create notes, edit titles and text, search their contents, and optionally link a note to the current page. Changes save automatically. An existing note migrates when the updated browser opens the profile. Regular windows in a profile share a notebook. Each private window keeps a temporary notebook until it closes.
- Select text on a page and choose Tools → Translate selection. LiteRust previews the text before you choose Open in Google Translate. The translation opens on Google's website. [Google Translate help](https://support.google.com/translate/answer/6142478)
- Choose Tools → Save page. The dialog depends on the installed WebView2 Runtime and page type. HTML saves the main document. Where MHTML or complete HTML is available, you can also save the supported resources. Forms, scripts, and external services may still need an internet connection. LiteRust shows a message if the API is unavailable. [WebView2 Save As](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2_25)
