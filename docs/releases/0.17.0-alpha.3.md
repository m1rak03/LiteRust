# LiteRust 0.17.0-alpha.3

## Рабочие пространства

- Откройте кнопку «Пространства» рядом с профилем. Создайте пространство с собственным именем или выберите существующее.
- «Вкладки этого окна» возвращает первоначальный набор вкладок. Пространство хранит свои вкладки, группы, выбранную вкладку и параметры Split View.
- В настройках пространства доступны имя, размер вкладок и цвет акцента. На новой вкладке пространства кнопка настройки главной страницы позволяет сохранить собственные быстрые сайты и компоновку.
- Чтобы открыть два пространства одновременно, откройте второе обычное окно и выберите другое пространство. Выбор уже открытого пространства переводит фокус в его окно.
- Все пространства одного профиля используют общие cookies, входы на сайты и историю. Пространства приватного окна живут до его закрытия.
- При включённой автовыгрузке фоновые страницы подчиняются общему лимиту окна. Сессия пространства сохраняет адреса и расположение вкладок, а выгруженная страница загружается снова при выборе.

## Workspaces

- Open the Workspaces button next to your profile. Create a named workspace or select an existing one.
- Tabs in this window returns to your original tabs. Each workspace remembers its tabs, groups, active tab, and Split View layout.
- Set the workspace name, tab density, and accent color in its settings. Customize its new tab page to save separate quick links and layout.
- For two workspaces at once, open another regular window and choose a different workspace. Selecting an already open workspace focuses its window.
- Workspaces within a profile share cookies, website sign-in, and history. Private window workspaces last until that window closes.
- With automatic unloading enabled, background pages follow the window's existing page limit. A workspace remembers addresses and tab layout, and an unloaded page loads again when selected.
