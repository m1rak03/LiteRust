# LiteRust 0.16.0-alpha.3

## Русский

- Выбор открытого профиля возвращает к его окну. Свёрнутое окно восстанавливается. Если Windows ограничивает перевод фокуса, значок окна мигает на панели задач.
- Раздел «Профили и аккаунты» показывает размеры данных, управляет архивом удалённых профилей и создаёт защищённые копии настроек и вкладок.
- Если файл каталога повреждён, LiteRust валидирует `profiles.json.bak`, восстанавливает каталог и сохраняет повреждённый оригинал.
- Окончательная очистка требует подтверждения и применяется к выбранному архиву.
- Исправлена линия у свёрнутой левой панели.

[Профили и восстановление](../PROFILES.md)

## English

- Selecting an open profile brings its window forward. If Windows restricts foreground activation, LiteRust flashes the taskbar icon.
- Profiles and accounts shows profile sizes, lets you restore or permanently delete archived profiles, and creates protected backups of settings and tabs.
- If the catalogue is damaged, LiteRust validates `profiles.json.bak`, restores it and preserves the damaged original.
- Fixed the line at the edge of the collapsed left sidebar.
