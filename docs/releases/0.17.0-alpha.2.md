# LiteRust 0.17.0-alpha.2

## Русский

- Откройте две вкладки. Щёлкните правой кнопкой по вкладке и выберите «Открыть рядом». В Split View можно выбрать вкладку для каждой области.
- Области можно разместить рядом или друг над другом, менять их пропорции ползунком или менять местами. Обводка показывает активную область. У каждой области своя адресная строка, навигация и прокрутка. Ctrl+L переносит фокус в адресную строку активной области.
- Кнопка «×» закрывает область, освобождает её WebView и оставляет вкладку в списке. При возврате на эту вкладку загружается сохранённый URL. «Выйти из разделения» возвращает обычный вид окна.
- Обе области используют сессию текущего профиля. В приватном окне обе работают в InPrivate. Режим восстановления сохраняет области, размеры, порядок, активную вкладку и группы по окнам.

## English

- Open two tabs, right-click one, and select Open beside. Each pane can display a different existing tab.
- Arrange the panes side by side or stacked. Use the slider to resize them or Swap to exchange their pages. The outline marks the active pane. Address entry, navigation, and scrolling are independent. Ctrl+L focuses the active pane's address bar.
- Close a pane with its × button. This releases its WebView and leaves its tab in the strip. Selecting that tab reloads its last URL. Exit split view returns to the regular layout.
- Both panes share the current local profile. Both panes in a private window use InPrivate. Session restore keeps the panes, ratio, order, active tab, and tab groups per window.

## WebView2

LiteRust uses two Wry child WebViews with independent controller bounds. A profile's WebView2 environment may share runtime processes across controllers, and the process count depends on Chromium site isolation. The memory fixture measures the private commit of the WebView2 processes reported by the environment and records how many processes Windows allowed it to read. [WebView2 process model](https://learn.microsoft.com/microsoft-edge/webview2/concepts/process-model), [Win32 process memory counters](https://learn.microsoft.com/en-us/windows/desktop/api/psapi/ns-psapi-process_memory_counters_ex).

### Локальный замер / Local memory sample

В таблице указан частный коммит памяти процессов WebView2 для тестовых HTML-страниц. Замер выполнялся на сборке для разработки Windows x64 с WebView2 Runtime 157.0.4341.60. В показания входят процессы интерфейса браузера. Это разовая проба для каждого режима окна.

The Windows x64 development build ran the same local HTML fixture in WebView2 Runtime 157.0.4341.60. The samples include all processes returned by the fixture's WebView2 environment, including the browser UI. Every reported process could be read. The values are private committed memory (MiB).

| Window | One page | Two pages |
| --- | ---: | ---: |
| Regular | 91.2 MiB, 5 processes | 123.9 MiB, 6 processes |
| InPrivate | 171.9 MiB, 7 processes | 202.4 MiB, 8 processes |

This is a single observation for each window mode on synthetic local pages. Subsequent measurements can vary with process sharing and the page workload.
