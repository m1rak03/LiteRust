# LiteRust 0.15.0-alpha.4 — свои горячие клавиши

- Основные сочетания Chrome: Ctrl+T/W/Shift+T, Ctrl+Tab, Ctrl+1…9, Ctrl+L, Ctrl+R/F5, Alt+стрелки, Ctrl+F, Ctrl+H/J/P/D, Ctrl+Shift+O/N, масштаб и F11.
- Настройки → Горячие клавиши: поиск команды, запись сочетания, отключение, сброс одной команды или всех. Конфликты отклоняются; обычный ввод и команды буфера обмена защищены.
- Назначения действуют в текущем окне и сохраняются для следующего запуска обычного профиля. Окна, уже открытые отдельно, автоматически не синхронизируются.
- При запуске окно сразу развёрнуто. F11 включает режим без панелей, Esc позволяет выйти даже после переназначения F11.

Это основные сочетания, а не полная совместимость Chrome: обычное второе окно Ctrl+N пока не поддерживается; Ctrl+Shift+N открывает приватное окно. Возврат закрытой вкладки хранит до 25 адресов в памяти текущего окна. Поиск страницы использует стандартное окно WebView2.

Установка, обновление, ярлыки и нативные сочетания проверяются Windows Actions перед публикацией.
