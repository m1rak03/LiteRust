# LiteRust 0.16.0-alpha.1 — локальные профили и рабочее пространство

- Обычное окно без отдельной системной строки: встроенные кнопки, перетаскивание, стандартное разворачивание. Прежний специальный fullscreen удалён; F11 больше не скрывает панели.
- Локальные профили с отдельными каталогами WebView2, именами и своими фото. Старый основной профиль остаётся на прежнем месте. Статусы сторонних аккаунтов не угадываются.
- Панель: по нажатию, при наведении или закреплённая; порядок, скрытие и ширина сохраняются в профиле.
- Быстрые сайты: отдельная плитка «+», добавление из закладок, редактирование, удаление и перетаскивание. Favicon загружается напрямую с HTTPS-сайта без стороннего сервиса.
- Главная: сеточный редактор, перенос, ширина, видимость, свои заголовки, отмена и сброс. Поиск с лупой использует выбранный поисковик и распознаёт адреса.

Ограничения: открытие профиля запускает отдельное окно; уже открытый профиль защищён блокировкой. Основной/текущий профиль не удаляется. Удалённые дополнительные профили сохраняются в ProfileTrash для восстановления. Внешние аватары и подтверждённые OAuth-статусы не предоставляются без официальной интеграции. Hover Snap Layouts на HTML-кнопке не заявляется; доступны штатные механизмы Windows. Несколько мониторов и реальные входы в сторонние сервисы требуют ручной проверки.

Перед публикацией Windows Actions проверяет управление окном, горячие клавиши, сохранение/изоляцию синтетических cookies, Local Storage и IndexedDB, установку и обновление. Результаты замеров хранятся отдельно; превосходство над другими браузерами не заявляется.
