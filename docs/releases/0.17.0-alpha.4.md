# LiteRust 0.17.0-alpha.4

## Адресная строка

- Подсказки объединяют открытые вкладки текущего пространства, закладки, быстрые сайты и посещённые страницы. Если сайт открыт, выбор подсказки переключает на его вкладку.
- Точные совпадения адресов идут первыми. Остальные позиции учитывают совпадение текста, закрепление, частоту и давность посещений.
- Текущая поисковая система указана рядом с адресом. Подходящие предыдущие запросы берутся из локальной истории этой системы. Запрос отправляется выбранной системе после подтверждения ввода или подсказки.
- Для команд введите «>» или название действия. Доступны настройки, загрузки, история, новая вкладка и выбор профиля.
- Стрелки выбирают результат. Enter выполняет действие. Tab дополняет поле выбранным результатом и оставляет фокус в нём. Esc закрывает список.
- Подсказки работают в обеих областях Split View. В приватном окне доступны его вкладки и быстрые сайты, команды и ввод нового запроса. История и закладки обычного профиля изолированы.

## Address bar

- Suggestions combine tabs in the current workspace, bookmarks, quick links, and visited pages. Choose an open site to switch to its existing tab.
- Exact address matches appear first. Other results take text similarity, pins, frequency, and recency into account.
- See the current search engine beside the address. Matching previous queries come from local history for that engine. A query is sent to the chosen engine when you submit it or choose a search result.
- Type “>” or an action name to find a command. Commands open settings, downloads, history, a new tab, or the profile picker.
- Use the arrow keys to select, Enter to act, Tab to complete in the field, and Esc to close the list.
- Suggestions work in both Split View panes. Private windows offer their own tabs and quick links, commands, and a new search. The regular profile's history and bookmarks remain isolated.
