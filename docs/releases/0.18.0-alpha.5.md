# LiteRust 0.18.0-alpha.5

## Интерфейс

- При обычном обновлении состояния панель сохраняет элементы иконок. Изменение названия вкладки, закладки или размера профиля обновляет соответствующий элемент. Поиск истории использует подготовленный текст.
- Быстрые сайты сохраняют иконки и ссылки при перестановке. Элементы управления редактора главной повторно используются при смене ширины или порядка блоков.
- Настройка снижения анимации применяется к новым вкладкам. Часы учитывают видимость главной страницы и показываемых блоков.

## Interface

- The toolbar retains its icons during ordinary state changes. Tab titles, bookmark rows, and profile sizes update in place. History search uses indexed row text.
- Moving quick links keeps their icon and link elements. Home editor controls are retained when a widget is resized or moved.
- New tabs observe reduced motion. The clock updates only when the page and relevant blocks are shown.

## Проверки и замеры

В тесте интерфейса при 200 обновлениях одной из 24 вкладок количество замен иконки кнопки панели составило 200 в alpha.4 и 0 в alpha.5. В списке вкладок инструментов MutationObserver зарегистрировал 5000 изменений дочерних узлов в alpha.4 и 200 в alpha.5. Сохранились узлы остальных строк, закладок и профилей. Сценарий использовал Chromium с шириной 690 px, масштабом 125% и включённым Reduced Motion.

Оба сравнения запускались 21 ноября 2026 года. Windows Debug-сборки, WebView2 Runtime 157.0.4341.60. В исходники 0.16.0-alpha.5 и 0.17.0-alpha.5 для замера ресурсов добавлена та же тестовая точка входа без изменения обычного запуска.

### Повторное открытие вкладок

Сценарий удерживал 24 загруженные вкладки и проверял удаление WebView после каждого закрытия. Промежуточные точки измерялись при восстановленном числе вкладок. [Длительный сценарий](../../tools/test-tab-churn-windows.ps1)

| Циклов | Время от начала, с | Процессы | Private commit, MiB |
| ---: | ---: | ---: | ---: |
| 0 | 9,5 | 30 | 1134,8 |
| 150 | 55,5 | 30 | 1178,6 |
| 300 | 101,6 | 30 | 1197,2 |

Число процессов во всех трёх точках равно 30. Частная выделенная память за 300 циклов выросла на 62,4 MiB. Этот замер не определяет причину роста. Показатели относятся к встроенным страницам и указанным условиям. Они фиксируют использование ресурсов и освобождение контроллеров в этом сценарии. Состояние долгоживущих внешних сайтов в замер не входило.
