# LiteRust 0.16.0-alpha.5

## Русский

- «Загрузки» показывает историю, ход передачи и доступные действия. Поиск работает по имени, источнику и статусу.
- WebView2 управляет файлами и сообщает, когда можно продолжить загрузку. После перезапуска незавершённые операции отмечаются как прерванные. После паузы окно можно закрыть, отменив загрузку или дождавшись её завершения после возобновления.
- «Открыть папку» открывает существующую папку файла в Проводнике. Очистка истории завершённых загрузок сохраняет файлы и действующие операции.
- Закладки можно искать, сортировать по названию, адресу или дате, переименовывать и перемещать между папками одного уровня. Удаление папки возвращает закладки в общий список.
- Экспорт HTML сохраняет папки. Существующий импорт HTML помещает закладки в общий список.
- Менеджеры используют существующие данные профиля. История загрузок приватного окна существует до его закрытия.

## English

- The downloads manager shows transfer progress and history. Search by filename, source or status, or filter by status.
- WebView2 reports which transfers support pause, resume and cancellation. An unfinished transfer appears as interrupted after restarting. To close a window with an ongoing transfer, cancel it or wait for it to finish.
- Open folder opens the existing destination in File Explorer. Clearing finished download history keeps files and ongoing transfers.
- Search bookmarks and sort by title, URL or date. Rename bookmarks and move them between single-level folders. Deleting a folder moves its bookmarks to the main list.
- HTML export includes folders. The current HTML importer places bookmarks in the main list.
- The managers use existing profile data. Private windows keep download history for the life of the window.
