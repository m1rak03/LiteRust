# Установка и диагностика

## Готовый выпуск

Скачивайте установщик только из Assets нужного выпуска в [официальном репозитории](https://github.com/m1rak03/LiteRust/releases). Проверьте номер версии и контрольную сумму, если она опубликована. Архив Source code не является установленным браузером.

Новые установщики публикуются только после успешного прохождения проверок выпуска.

## Чёрное окно

1. Закройте LiteRust и убедитесь, что WebView2 Runtime установлен.
2. Используйте весь комплект приложения: не переносите отдельный EXE без соседних DLL.
3. Приложите к обращению журнал запуска, версию Windows, WebView2 и LiteRust. Не прикладывайте профиль, cookies или VPN-ключи.
4. Если журнал сообщает, что Runtime найден, отсутствие Runtime уже не объясняет проблему. Нужна проверка инициализации интерфейса и рендеринга; не удаляйте профиль для диагностики без резервной копии.

## Сборка дистрибутива

Приложение собирается на Windows с Rust MSVC, Visual Studio Build Tools и Windows SDK: `cargo build --locked --release`.

В дистрибутив включаются соответствующий x64 `WebView2Loader.dll`, компоненты Xray, а для системного режима VPN — `sing-box.exe`, `libcronet.dll`, `packaging/system-vpn.ps1` и лицензии. Перед NSIS соберите нативный helper закрытия браузера: `rustc --edition=2021 -O -C target-feature=+crt-static -C strip=symbols tools/installer-close.rs -o packaging/close-browser.exe`. Он не завершает процессы принудительно и не требует PowerShell для обновления. Полный установщик по `packaging/setup.nsi` требует подготовки офлайн-установщика WebView2 и остальных входных файлов. Утилиты и версии сторонних компонентов описаны в `vendor/`.

Не объявляйте артефакт CI полноценным установщиком, если он содержит только EXE и Xray. Проверка компиляции не заменяет запуск установленного приложения.

## Профиль и обновления

Обычный профиль находится в `%LOCALAPPDATA%\LiteRustBrowser`. Основной профиль сохраняет этот путь. Дополнительные профили 0.16 находятся в `Profiles/<id>` внутри этого каталога; каталог профилей — `profiles.json`. Не удаляйте их при обновлении. Для резервной копии закройте все окна LiteRust и скопируйте весь каталог; DPAPI-привязка к учётной записи Windows ограничивает перенос на другой компьютер. После перехода на DPAPI старые версии до 0.13.0-alpha.2 не читают зашифрованный профиль; учитывайте это при откате.

## Медицинская аттестация и TLS

Настоящий адрес сайта: https://lkmr.egisz.rosminzdrav.ru/. Страница `ya.ru/project/browser/error3/…` — пояснение Яндекса о сертификатах, а не сам сайт.

LiteRust использует WebView2. Выбор поисковика Яндекс не добавляет поддержку сертификатов Яндекс Браузера. Откройте официальные инструкции https://www.gosuslugi.ru/tls и проверьте источник и издателя сертификатов перед установкой в Windows. Добавление корневого сертификата расширяет системное доверие. LiteRust не импортирует корни автоматически и не отключает проверку TLS.

Доступ к сайту после настройки доверия нужно проверить на целевой Windows. Ошибки авторизации, клиентских сертификатов или доступности сервиса могут требовать отдельной диагностики.
