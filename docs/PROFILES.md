# Профили LiteRust

Профиль хранит настройки LiteRust и собственные данные WebView2. Выберите профиль в «Профили и аккаунты». Если его окно уже открыто, LiteRust восстановит его из свёрнутого состояния и попытается перевести фокус. Windows может вместо этого подсветить значок окна на панели задач.

## Архив и занимаемое место

Сначала закройте окно профиля и выберите «Удалить». LiteRust переместит каталог профиля в архив. Из архива профиль можно восстановить с тем же идентификатором и данными. «Удалить навсегда» показывает последствия и удаляет выбранную папку профиля после подтверждения. Файлы, которые были загружены в другие папки, сохраняются.

Размер — сумма размеров файлов профиля по данным файловой системы. Подсчёт выполняется в фоне и пропускает ссылки на другие папки. Для основного профиля исключены каталоги других профилей и архива.

## Восстановление

Если основной каталог `profiles.json` недоступен, LiteRust проверяет резервный `profiles.json.bak`: допустимый размер, защиту DPAPI при наличии, JSON, уникальные идентификаторы и существование выбранной записи. При восстановлении найденный оригинал сохраняется как `profiles.corrupt-….json`. Если обе копии повреждены, LiteRust сообщает об ошибке и сохраняет их для восстановления.

«Копия настроек и вкладок» сохраняет в `Backups` текущего профиля отдельный файл метаданных. Копия защищена Windows DPAPI и предназначена для той же учётной записи Windows. Она содержит настройки, вкладки, историю и закладки. Cookies, LocalStorage и IndexedDB хранятся в каталоге WebView2.

Чтобы вручную восстановить метаданные, штатно закройте окно профиля, отложите текущие `browser-data.json` и `browser-data.json.bak` и скопируйте выбранную копию в `browser-data.json` того же профиля. Для резервирования папки WebView2 дождитесь завершения процессов движка для этого профиля, чтобы SQLite и другие хранилища были закрыты. [Жизненный цикл процессов WebView2](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/process-related-events).

## Проверка сессий

Сценарий `tools/test-sessions-windows.ps1` проверяет cookies, LocalStorage и IndexedDB на локальном тестовом сайте. Он перезапускает тестовый процесс, проверяет два разных обычных профиля, а также запись в InPrivate и чистое состояние при следующем запуске InPrivate.
