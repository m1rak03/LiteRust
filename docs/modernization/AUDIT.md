# Аудит исходной архитектуры — 17 ноября 2026

База: 0.15.0-alpha.4. Проверены исходники Rust, HTML/JS, зависимости Cargo, сборка и установка.

| Подсистема | Подтверждено в коде | Изменения по ТЗ |
|---|---|---|
| Окно | Tao 0.37.2, системный заголовок, отдельный Borderless fullscreen | Убрать fullscreen, использовать undecorated обычное окно, встроенные controls и native drag/resize |
| WebView | Wry 0.57.2, WebView2; toolbar/dock/page — отдельные дочерние окна | Сохранить объекты; учитывать native z-order при шторке |
| Сессии | Постоянный LOCALAPPDATA/LiteRustBrowser/WebView2; общий WebContext для вкладок | Сохранить старый путь для основного профиля, отдельные каталоги для новых |
| Профиль | Единственный профиль, OS file lock, DPAPI JSON, backup | Добавить локальный каталог профилей, не переносить существующие cookies |
| Аккаунты | Официальные URL, нет OAuth и определения личности | Статус «неизвестен», локальные имена/аватары не выдавать за внешнюю личность |
| Вкладки | HashMap live controllers, generation guards, LRU; закрытие удаляет WebView | Сохранить модель и запрет выгрузки активных downloads |
| Панель | 54 px в четырёх позициях, отдельная WebView | Добавить режимы/расширение/порядок без пересоздания |
| Главная | Шаблон Rust, 3 layout, плитки из bookmarks, нет отдельного CRUD/layout editor | Добавить модель быстрого доступа и сеточный редактор |
| Безопасность | Привилегированный IPC только toolbar/dock; сайт без IPC; allowlist внутренних команд | Не расширять IPC произвольных сайтов; валидировать внутренние данные |
| Производительность | Лимит живых вкладок, опциональная выгрузка, все события на STA | До/после сравнивать одни сценарии; не заявлять выигрыша по ОЗУ без замера |

Зависимости не меняются ради интерфейса. Сервер и облачные аккаунты LiteRust не нужны.

Риски: Snap hover над HTML-кнопкой не равен native caption button; нужны отдельные испытания Windows. Google может отвергать embedded WebView; наличие cookies не доказывает вход. Системный VPN действует на все процессы ПК, независимо от локального профиля. Реальная OAuth-проверка и внешние аватары требуют официальной интеграции, которой пока нет.

## План проверяемых этапов
1. Аудит (этот файл).
2. Окно без системной строки; удаление legacy fullscreen и миграция его shortcut.
3. Локальные профили и изолированные каталоги WebView2.
4. Локальные аватары и честные статусы сервисов.
5. Шторка, настройки, порядок и native overlay.
6. Отдельные быстрые ссылки с CRUD и порядком.
7. Сеточный редактор главной с отменой, сбросом и сохранением.
8. Поиск и визуальная персонализация.
9. Регрессии, нативные проверки, измерения и отчёт.

Тесты прошлых релизов не считаются проверкой новых функций. Несколько мониторов, Snap hover и реальные логины требуют ручной проверки на Windows; до неё результат не заявляется.
