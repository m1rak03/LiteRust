# Локальная проверка 0.14.0-alpha.2

Дата: 16 ноября 2026 года. Эта доработка выполнена локально без обращения к GitHub; публикация и сборка Windows-установщика отложены.

| Проверка | Результат |
| --- | --- |
| `cargo test --offline --locked --no-default-features --lib` | 49 тестов прошли на Linux |
| Windows x64 target Clippy, все targets, `-D warnings` | Прошёл; это проверка компиляции, не запуск Windows |
| `node tools/check-source.mjs` | Прошёл |
| `node tools/test-settings.cjs` | Настройки, защита домашнего адреса, черновик формы/ползунка, сброс, контраст акцента, три компоновки и узкое окно — прошли |
| `node tools/test-security.cjs` | Вставленные script/onerror заблокированы, адресная строка работает |
| `node tools/test-ui.cjs` | 275 сочетаний оформления, IPC, меню, экранирование заголовков — прошли |
| `node tools/test-v013.cjs` | Регрессия вкладок, фон из файла/URL, свои иконки, анимации — прошла |

UI проверялся в Chromium 151.0.7922.34 через Playwright. Сохранение и чтение новых настроек проверено через файл профиля. Linux-тест не выполняет Windows DPAPI: его нативную проверку для этой локальной версии ещё нужно провести на Windows.

Предыдущая удалённая сборка 0.14.0-alpha.1 была запущена до потери авторизации. Её итоговый статус в этой сессии не подтверждён. Локальная alpha.2 содержит дополнительные изменения и не объявляется готовым проверенным EXE.

Локальные журналы находятся в `audit-logs/local014-*.log` и намеренно не включаются в исходный архив. Архив не содержит кэш сборки или пользовательский профиль. Скрипт упаковки проверяет CRC записей ZIP и создаёт отдельный файл SHA-256.
