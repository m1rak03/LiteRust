# Безопасность LiteRust

## Выпуск 0.13.0-alpha.2

- История, закладки, вкладки и настройки в browser-data.json, а также .bak и pre-v09 копии шифруются Windows DPAPI для текущей учётной записи. Старые файлы мигрируют при запуске. Повреждённые данные не заменяются пустым профилем.
- Это не полное шифрование диска: файлы WebView2, кэш сайтов, загруженные файлы, экспорт закладок и старые внешние копии профиля сюда не входят. Ключи VPN уже защищены DPAPI.
- Обычные сайты не получают IPC браузера и доступ к COM host objects. DevTools отключены; проверка репутации WebView2 включена. Для чувствительных разрешений сохраняются запросы/запреты.
- Скрипты служебной панели используют случайный CSP nonce. Внешние скрипты, inline event handlers, фреймы и сетевые подключения этой панели запрещены политикой CSP.
- Системные PowerShell и rundll32 запускаются по пути из Windows API, без поиска в текущем каталоге и PATH.
- Включён Chromium site-per-process. Он может увеличивать расход памяти. Наследуемые переменные WebView2 для подмены движка, профиля и отладочных аргументов очищаются до создания потоков.

DPAPI не защищает от вредоносной программы, уже работающей под тем же Windows-пользователем, администратора или украденной активной сессии. Требуются обновления Windows и Evergreen WebView2. Это усиление защиты, а не независимый пентест или гарантия отсутствия уязвимостей.

После миграции старые версии LiteRust не смогут читать зашифрованный профиль. Для переноса закладок используйте явный экспорт; не переименовывайте зашифрованные файлы в обычный JSON. Миграция не удаляет ранее сделанные пользователем копии с диска/из облака.

## Проверки

Регрессионный тест CSP проверяет блокировку вставленного script и onerror с сохранением работы адресной строки. Windows-тест DPAPI проверяет чтение и отказ при изменении шифротекста. Проверка установщика проверяет миграцию настроек и шифрование исторических резервных копий.

OSV, 2026-11-16: проверены 312 registry-зависимостей Cargo.lock. glib 0.18.5 (RUSTSEC-2024-0429) относится к Linux-ветке зависимостей и отсутствует в Windows x64 сборке; Linux-сборка не заявляется защищённой. fxhash 0.2.1 и proc-macro-error 1.0.4 отмечены как неподдерживаемые (RUSTSEC-2025-0057, RUSTSEC-2024-0370); это остаётся техническим долгом, а не закрытой уязвимостью. Аудит Cargo не охватывает Microsoft WebView2, Xray и sing-box.

## Сообщение о проблеме

Передайте владельцу репозитория версию, минимальные шаги воспроизведения и ожидаемый/фактический результат. Не размещайте публично пароли, cookies, VPN-ключи, профиль или рабочую цепочку кражи данных пользователей. Для теста используйте отдельный профиль и вымышленные данные.
