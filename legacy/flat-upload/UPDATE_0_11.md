# Проверка 0.11.0-alpha.1

Изменения: новая вкладка по образцу Google, постоянный профиль для входа, закреплённая кнопка аккаунта, перемещаемая панель функций, VPN-хаб по образцу Happ и встроенный Xray.

## Проверено в этой среде

- Rust core tests: 40 тестов, включая безопасные HTML-ярлыки, 4 геометрии панели, импорт протоколов/подписок, ограничения размера, отсутствие секретов в Debug/ошибках, сохранение оформления и прежние проверки профиля.
- Windows GNU all-targets Clippy с `-D warnings`, release cross-build, rustfmt, проверка JS и источников.
- Chromium: 275 сочетаний дизайнов/тем, все 4 положения панели, аккаунт слева сверху, импорт и очистка поля ключа, серверы/поиск/выбор, подтверждение и отмена переключения, недоступность изменения VPN в приватном окне, узкая ширина.
- Новая вкладка: кнопка входа справа сверху, 4 стандартных ярлыка, 9 сервисов Google, закрытие меню Escape, ссылка оформления, ширина 640px, корректное кодирование поискового запроса. Поиск перехвачен локальным тестом, без отправки запроса Google.
- 11 тестовых конфигураций разных протоколов/транспортов приняты настоящим Xray 26.11.9 через `run -test -config stdin:`. Ключи в них вымышленные.
- Локальная интеграция Chromium → Xray → тестовый HTTP-прокси. Страница открылась через заданный прокси; после остановки Xray Chromium получил ошибку прокси. Удалённый провайдер и реальные VPN-ключи не использовались.

## Важные границы

Проверки выполнялись на Linux; нативное приложение Windows, Microsoft WebView2, сохранение реального Google-входа, вызовы Windows DPAPI/Job Object и поведение всех видов WebRTC/UDP на Windows не запускались. Исходящие системные запросы и обновления среды не являются трафиком вкладок. Кросс-сборка не доказывает отсутствие всех сетевых утечек. Для окончательной проверки нужен запуск на Windows и тест с ключом пользователя; сам ключ не нужно публиковать в чате.

Google может отказать встроенному движку в авторизации, отозвать сессию либо запросить вход повторно. OAuth-привязки оболочки и Google Password Manager API нет. Нет имитации статуса «вы вошли», имени/аватара или бессрочного входа.

VPN применяется после подтверждённого перезапуска. Автоматический переход на прямой доступ при смерти Xray не предусмотрен. Настройки иных уже открытых процессов LiteRust требуют их закрытия/перезапуска. Кнопка проверки соединения выполняет реальный HTTPS-запрос только по нажатию; она не показывает фиктивный ping, трафик или срок подписки.

Новая вкладка не получает общий IPC: доверенная навигация `literust://appearance` только открывает панель оформления после проверки поколения WebView и того, что вкладка остаётся новой. Общий IPC доступен только панели управления и доку; док имеет отдельный ограниченный список команд.
